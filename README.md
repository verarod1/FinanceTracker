# Finance Tracker 

Минималистичное десктопное приложение для учета личных финансов, написанное на C++ с использованием фреймворка Qt.

## Ключевые возможности

* **Учет транзакций:** Быстрое добавление доходов и расходов с указанием точной суммы, категории и даты.
* **Умная фильтрация (Excel-style):** Клик по заголовкам таблицы («Тип», «Категория», «Дата») открывает интерактивное меню с чекбоксами. Меню динамически адаптируется под уже выбранные параметры и скрывает лишние строки.
* **Детальная статистика:** Автоматический подсчет общего баланса за месяц. Визуализация распределения средств по категориям с помощью цветных индикаторов.
* **Годовая аналитика:** Специальный модуль визуализации, который строит столбчатые диаграммы за все 12 месяцев. Включает в себя автоматическую генерацию цветовой палитры для категорий, структурированную легенду и систему всплывающих подсказок при наведении.
* **Автономность:** Все записи автоматически сохраняются в локальный текстовый файл `data.txt` и мгновенно загружаются при следующем запуске.

## Стек технологий

* **Язык программирования:** C++
* **GUI-фреймворк:** Qt (модуль QtWidgets)
* **Архитектура:** Разделение логики хранения данных (`FinanceManager`) и пользовательского интерфейса (`FinanceApp`).
